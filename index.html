Configuración inicial

Para leer y guardar tus gastos esta página necesita un token de GitHub. Se guarda solo en este dispositivo.

  1. En GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Only select repositories → costos.
  3. Permissions → Add permissions → Contents → Read and write.
  4. Generá el token, copialo y pegalo acá:

Si te lo vuelve a pedir cada vez que entrás: abrí la página directo en Safari o Chrome (no desde el navegador interno de otra app ni en modo privado).
